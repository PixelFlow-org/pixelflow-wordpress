How to run. PHP suites are plain scripts: php tests/test-<name>.php (exit 0 = green). Component tests: npm run test from app/source/. Local admin E2E: Playwright from e2e/. The live storefront suite runs against the rift test site — invoke it through the test-live-woo-events skill rather than by hand, since it builds and installs the plugin first.

“Partial” means the behaviour is touched by a test that asserts something else; “Not covered” means no automated test exercises it today.
