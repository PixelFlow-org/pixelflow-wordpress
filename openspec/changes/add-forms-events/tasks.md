- [x] 1.1 Create `includes/forms/` and define the normalised submission shape the whole feature speaks: `source`, `form_id`, `form_title`, and `fields` as key, value, type, label — with a sanitizer that discards everything else an adapter may pass

Keep the two lists as data, in the same place and shape as the 2.2 patterns
- [x] 2.7 Classify a form as high or medium confidence: high when it has a native email or phone field and its title matches no exclusion pattern; medium otherwise. Derive the suggested event — `CompleteRegistration` for a title matching a registration pattern or an email-only form, `Lead` otherwise. A form is email-only when its email field is its only input field; each adapter declares its plugin's non-input field types (hidden, submit, captcha and honeypot, consent or acceptance checkbox, HTML and divider blocks), which are not counted

- [x] 4.7 Scope the walk with one rule used both for listing and for deciding whether a configured form still exists: every post Elementor renders, ordinary or `elementor_library` (popups included), in any status except `trash` and `auto-draft`, and never a `revision`. Use WordPress's own `post_status => 'any'`, which already excludes both statuses because each is registered as internal (`wp-includes/post.php:732` for `trash`, `:747` for `auto-draft`; `register_post_status()` defaults `exclude_from_search` to `internal` at `post.php:1510`, and `WP_Query` turns that into an exclusion at `class-wp-query.php:2667`); do not hand-roll a status list that silently readmits either. Draft, pending and scheduled posts are listed deliberately: Elementor accepts a submission from WordPress preview without checking post status, so their forms can send
- [x] 4.8 Fluent Forms adapter: forms by form id, fields by their `name` attribute with the composite name field's sub-inputs as separate keys, `fluentform/submission_inserted` at priority 20 with its three arguments; confirm on the installed plugin how a spam-flagged entry is represented and skip it, rather than assuming the Gravity Forms shape
- [x] 4.9 Ninja Forms adapter: forms by form id, fields by field key; confirm the post-submission action's name and the shape of its submitted data against the installed plugin before writing the adapter, the same way 4.8 does for Fluent Forms, and skip an entry the plugin flagged as spam
- [x] 4.10 Record a form that no longer exists as missing: keep its stored event and map, refuse to enable it, and send nothing for it.
